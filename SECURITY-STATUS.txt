TECSPA E2EE STATUS — STAGE 4 PARTIAL MEMBER-PROFILE SLICE

The web adapter's member CRUD/read/fronting operations and web member-create form now use encrypted vault records.

THIS IS NOT FULL E2EE.
- Existing plaintext member rows are not migrated.
- Legacy member/import APIs remain and can expose or write plaintext.
- Chat, journal, front history, polls, imports, media, sharing, and desktop SQLite are not fully integrated.
- Do not claim zero-knowledge security or use this as a complete privacy guarantee.
- A clean build/type-check has not been verified in this environment.

See docs/E2EE-STAGE-4-MEMBER-PROFILES.md before testing.
