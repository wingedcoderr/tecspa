# TECSPA™

### The Extremely Customizable Plural App™

A customizable desktop app for plural systems, built to give you a place to organize your system, keep track of fronting, customize member profiles, and make TECSPA feel like *your* space.

> ⚠️ TECSPA is currently in early development. Things may change, break, or be redesigned as the project grows.

---

## ✨ Features

### 👥 Member Profiles

Create detailed profiles for each member of your system.

- Names
- Pronouns
- Aliases
- Roles
- Status
- About sections
- Interests
- Fronting triggers
- Custom fields
- Custom avatars
- Custom banners

---

### 🔄 Fronting

Keep track of who is currently fronting.

- Set a member as fronting
- View fronting history
- Record when fronting started and ended
- Keep notes alongside fronting entries

Your fronting data is stored locally in TECSPA's SQLite database.

---

### 📝 Custom Fields

Don't want your member profiles to be limited to predefined fields?

Create your own.

TECSPA supports:

- Text
- Long text
- Numbers
- Checkboxes
- Dates
- Tags

You decide what information your system wants to keep.

---

### 🎨 Themes & Customization

TECSPA is designed to be extremely customizable.

Choose from multiple visual themes and customize things such as:

- Colors
- Fonts
- Panel appearance
- Borders
- Shadows
- Decorative elements
- Backgrounds
- UI styling

The goal is simple:

**Your system, your aesthetic.**

---

### 💬 System Activity

TECSPA is also being built around communication and shared system activity.

Planned/implemented activity features include:

- 💬 Chat between headmates
- 📖 Journals
- 📝 Notes
- 📊 Polls

These features are designed to give systems a shared space inside the application rather than just a database of member information.

---

### 📥 Ampersand Import

Already have your system stored in Ampersand?

TECSPA includes an importer for Ampersand JSON exports.

It can import things such as:

- Members
- Member information
- Avatars
- Banners
- Custom fields
- Fronting history

The importer provides a preview before anything is written to the database.

---

### 💾 Local & Private

TECSPA uses a local SQLite database.

Your system data is stored locally on your computer rather than requiring a remote account or server.
